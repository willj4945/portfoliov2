About me

I’m Will Johnson, a security engineer with six years in federal cybersecurity. I build security tooling, secure cloud infrastructure, and the DevSecOps pipelines that connect them.

My tools turn scanner output and cloud configuration into evidence people can act on: tracing a container CVE to the layer that introduced it, or scoring an AWS Organization against the NIST 800-53 controls actually in scope. I write them in Go and Python, and I care about the same things in my own projects that I ask of others — signed releases, SBOMs, provenance, and CI that gates on security.

I came up through GRC — NIST RMF, FISMA, CMMC, and leading accreditation activities — so I know what an assessor needs and build tools that produce it. I’ve partnered with engineering teams to embed security controls into CI/CD pipelines and automated compliance work that cut manual overhead by 30%+.

What I work on

  • Security tooling — Go and Python tools for supply chain analysis, scanning, and evidence generation
  • Cloud security — AWS architecture and hardening, infrastructure as code with Terraform
  • DevSecOps — SAST, DAST, SCA, and container scanning built into CI/CD
  • Software supply chain — SBOMs, SLSA provenance, signed artifacts, image attribution
  • Compliance as code — NIST 800-53 / RMF and DoD Cloud SRG mapped to real infrastructure

Community

I’m active in the DoD/federal tech community, including the DevSecOps Community of Practice and open-source contributions to the .mil GitHub ecosystem. My lab notebook, Ramblings, is where I share experiments and notes that might be useful to others.
